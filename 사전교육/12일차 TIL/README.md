## 1. Class란?

Class는 **변수(Variable)와 메서드(Method)로 이루어진 템플릿**이다.

```text
Class
├── Variable
└── Method
```

이전 강의에서 변수는 데이터를 저장하고, 메서드는 데이터를 다루는 행위라고 학습하였다.

이번 강의에서는 이러한 변수와 메서드가 하나의 Class를 구성한다는 내용을 학습하였다.

---

## 2. Class의 구성 요소

Class는 크게 다음 두 요소로 구성된다.

### Variable

Class에서 사용하는 데이터를 저장한다.

### Method

Class에서 데이터를 이용하여 특정 동작을 수행한다.

따라서 Class의 기본적인 구조를 다음과 같이 이해할 수 있다.

```text
Class = Variable + Method
```

---

## 3. Instance와 Class

강의에서는 Class에 선언된 변수와 메서드는 **Instance의 소유**라고 설명하였다.

Class를 기반으로 객체를 생성하면 해당 객체를 통해 Class에 선언되어 있는 변수와 메서드를 사용할 수 있다.

```text
Class
  ↓
객체 생성
  ↓
Instance
  ↓
변수 / 메서드 사용
```

---

## 4. 객체 생성

Class에 선언되어 있는 변수와 메서드를 외부에서 사용하려면 **객체를 생성해야 한다.**

즉, Class를 선언하는 것만으로 외부에서 바로 변수나 메서드를 사용하는 것이 아니라, 객체를 생성한 뒤 해당 객체를 통해 접근하는 방식이다.

```text
Class 선언
   ↓
객체 생성
   ↓
Class에 선언된
Variable / Method 접근
```

---

## 5. 여러 객체 생성

강의에서는 하나의 Class를 기반으로 여러 객체를 생성할 수 있다는 내용을 학습하였다.

```text
        Class
       /  |  \
      /   |   \
객체 1  객체 2  객체 3
```

하나의 Class를 템플릿으로 사용하여 여러 객체를 만들어 사용할 수 있다.

---

## 💡 새롭게 알게 된 점

이번 강의를 통해 Class가 단순히 코드를 묶어두는 공간이 아니라 **변수와 메서드를 포함하는 템플릿**이라는 점을 다시 정리할 수 있었다.

또한 Class에 변수와 메서드를 선언했다고 해서 외부에서 바로 사용할 수 있는 것이 아니라, 객체를 생성한 뒤 해당 객체를 통해 접근해야 한다는 점을 알게 되었다.

하나의 Class를 기반으로 여러 객체를 생성할 수 있다는 점도 Class와 Instance의 관계를 이해하는 데 중요한 내용이었다.
