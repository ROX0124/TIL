## 2. `git commit -am` 사용 시 주의점

Git에서는 `-am` 옵션을 이용해 `add`와 `commit`을 한 번에 진행할 수 있다.

하지만 **새롭게 생성된 파일이 있는 경우에는 `-am` 옵션을 사용할 수 없다.**

즉, `-am` 옵션은 **untracked file이 없는 경우에 한해서 사용할 수 있다.**

```text
새로운 파일이 없는 경우
→ git commit -am 사용 가능

새로운 파일이 있는 경우
→ git add 과정 필요
```

따라서 새 파일을 생성한 경우에는 먼저 해당 파일을 Git이 추적할 수 있도록 추가하는 과정이 필요하다.

## 3. 과거 커밋으로 돌아가는 방법

Git에서는 이전 커밋 상태로 돌아가기 위한 방법으로 `reset`과 `revert`를 사용할 수 있다.

### reset

`reset`은 원하는 시점의 커밋으로 돌아간 뒤, 그 이후의 내역을 제거하는 방식이다.

```text
현재
↓
원하는 과거 시점으로 이동
↓
이후 내역 제거
```

### revert

`revert`는 되돌리고 싶은 커밋의 작업 내용을 반대로 실행하는 방식이다.

즉, 기존의 커밋 이력을 직접 삭제하기보다는 되돌리는 작업을 새로운 변경으로 처리한다.

---

## 4. reset과 revert

강의에서 학습한 내용을 기준으로 정리하면 다음과 같다.

| 구분 | reset | revert |
| --- | --- | --- |
| 목적 | 특정 시점으로 이동 | 특정 커밋의 작업 되돌리기 |
| 이후 내역 | 제거 | 기존 이력 유지 |
| 방식 | 과거 상태로 돌아감 | 반대 작업 수행 |

두 방법 모두 이전 상태로 돌아가는 데 사용되지만, 처리 방식에는 차이가 있다.

---

## 5. Branch

Branch는 하나의 Git 프로젝트에서 작업 흐름을 여러 갈래로 나누어 관리하기 위한 기능이다.

강의에서는 Branch를 **분기된 다른 차원**, 즉 서로 다른 작업 공간과 같은 개념으로 설명하였다.

```text
main
  │
  ├── branch A
  │
  └── branch B
```

Branch를 활용하면 기존 작업과 분리된 공간에서 새로운 기능이나 수정 작업을 진행할 수 있다.

---

## 6. Branch 생성

새로운 브랜치는 다음 명령어를 이용해 생성할 수 있다.

```bash
git branch 브랜치명
```

예를 들어 다음과 같이 작성할 수 있다.

```bash
git branch feature
```

이 명령어는 새로운 브랜치를 생성한다.

---

## 7. Branch 이동

다른 브랜치로 이동할 때는 `git switch`를 사용한다.

```bash
git switch 브랜치명
```

예를 들어 `feature` 브랜치로 이동한다면 다음과 같이 작성할 수 있다.

```bash
git switch feature
```

### 브랜치 생성과 동시에 이동

다음 명령어를 사용하면 새로운 브랜치를 생성하면서 동시에 해당 브랜치로 이동할 수 있다.

```bash
git switch -c 브랜치명
```

```text
git branch
→ 브랜치 생성

git switch
→ 브랜치 이동

git switch -c
→ 브랜치 생성 + 이동
```

---

## 8. Branch 목록 확인

현재 존재하는 브랜치 목록은 다음 명령어를 이용해 확인할 수 있다.

```bash
git branch
```

이를 통해 프로젝트에서 어떤 브랜치들이 존재하는지 확인할 수 있다.

---

## 9. Branch 삭제

브랜치를 삭제할 때는 `-d` 옵션을 사용할 수 있다.

```bash
git branch -d 브랜치명
```

강제로 삭제해야 하는 경우에는 `-D` 옵션을 사용한다.

```bash
git branch -D 브랜치명
```

따라서 두 명령어를 구분해서 사용할 수 있다.

```text
-d → 브랜치 삭제
-D → 브랜치 강제 삭제
```

---

## 10. Branch 이름 변경

브랜치 이름은 `-m` 옵션을 이용하여 변경할 수 있다.

```bash
git branch -m 기존브랜치명 새브랜치명
```

이를 통해 기존에 생성한 브랜치의 이름을 새로운 이름으로 변경할 수 있다.

---

## 💡 새롭게 알게 된 점

이번 강의를 통해 `git commit -am`을 사용하면 항상 `add`와 `commit`을 한 번에 처리할 수 있는 것이 아니라, **Git이 아직 추적하고 있지 않은 새로운 파일이 있는 경우에는 사용할 수 없다는 점**을 알게 되었다.

또한 Git에서 과거 상태로 돌아가는 방법이 하나만 있는 것이 아니라 `reset`과 `revert`처럼 서로 다른 방식이 있다는 점을 이해했다.

특히 Branch를 이용하면 하나의 프로젝트 안에서도 서로 다른 작업 공간을 만들어 작업할 수 있다는 점이 인상적이었다.

`git branch`, `git switch`, `git switch -c` 등의 명령어를 통해 브랜치를 생성하고 이동할 수 있으며, 필요하지 않은 브랜치는 삭제하거나 이름을 변경할 수도 있다는 것을 알게 되었다.
