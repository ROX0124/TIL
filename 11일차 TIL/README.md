## 1. 변수란?

변수는 **데이터를 담을 수 있는 그릇**이라고 이해할 수 있다.

Java에서는 변수에 어떤 종류의 데이터를 저장하는지에 따라 변수 타입을 구분할 수 있다.

크게 다음과 같이 나눌 수 있다.

```text
변수 타입
├── 기본 타입
└── 참조 타입
```

---

## 2. 기본 타입

기본 타입은 **데이터의 값을 직접 담는 타입**이다.

강의에서는 기본 타입을 숫자형, 문자형, 논리형 등으로 구분하였다.

### 숫자형

숫자형은 다시 정수형과 실수형으로 나눌 수 있다.

#### 정수형

```java
byte
short
int
long
```

#### 실수형

```java
float
double
```

---

### 문자형

하나의 문자를 표현할 때 `char`를 사용한다.

```java
char
```

예시는 다음과 같다.

```java
'a'
```

---

### 논리형

참 또는 거짓을 표현할 때 `boolean`을 사용한다.

```java
true
false
```

---

### 문자열

문자열을 다룰 때는 `String`을 사용한다.

```java
String
```

---

## 3. 참조 타입

참조 타입은 데이터 자체의 값을 담는 것이 아니라 **주소값을 담는 타입**이다.

강의에서는 기본 타입을 제외한 모든 타입이 참조 타입에 해당한다고 설명하였다.

```text
기본 타입
→ 값 저장

참조 타입
→ 주소값 저장
```

---

## 4. 변수 선언 방법

Java에서 변수를 선언하는 기본적인 구문은 다음과 같다.

```java
[접근지정자] [변수타입] [변수명] = value;
```

예를 들어 다음과 같은 구조로 이해할 수 있다.

```text
접근지정자
   ↓
변수 타입
   ↓
변수명
   ↓
값
```

강의에서는 접근지정자로 다음과 같은 키워드를 살펴보았다.

```java
public
private
```

접근지정자는 경우에 따라 생략할 수 있다.

---

## 5. 변수 이름 작성

강의에서는 변수 이름을 작성할 때 **Camel Case 방식으로 사용하는 것이 이상적**이라고 학습하였다.

예를 들면 이전 강의에서 살펴봤던 다음과 같은 형태이다.

```java
engSum
```

여러 단어를 연결할 경우 첫 단어 이후 새로운 단어의 첫 글자를 대문자로 작성하는 방식이다.

```text
eng + Sum
    ↓
engSum
```

또한 강의에서는 변수 이름과 관련하여 대문자로 시작하지 않는 방식으로 작성하는 것을 학습하였다.

---

## 6. `=`의 의미

프로그래밍에서 `=`은 수학에서 사용하는 등호와 의미가 다르다.

Java에서는 **우변에 있는 값을 좌변에 할당하는 역할**을 한다.

```java
int age = 20;
```

이를 다음과 같이 이해할 수 있다.

```text
20
 ↓
age
```

즉, 오른쪽에 있는 `20`이라는 값을 왼쪽 변수 `age`에 저장하는 것이다.

---

## 7. 변수의 선언 위치

변수는 선언되는 위치에 따라 구분할 수 있다.

강의에서는 다음 두 가지를 살펴보았다.

```text
전역변수
지역변수
```

변수가 어디에서 선언되는지에 따라 사용되는 범위가 달라질 수 있다.

---

## 8. 메서드란?

메서드는 **데이터를 다루는 행위**라고 이해할 수 있다.

변수가 데이터를 저장하는 역할을 한다면, 메서드는 해당 데이터를 이용하여 특정 동작을 수행하는 역할을 한다.

```text
변수
→ 데이터

메서드
→ 데이터를 다루는 행위
```

---

## 9. 메서드의 기본 구조

Java에서 메서드는 다음과 같은 형태로 작성할 수 있다.

```java
[접근지정자] [반환타입] [메서드이름]() {

}
```

메서드는 크게 다음 요소를 포함할 수 있다.

- 접근지정자
- 반환타입
- 메서드 이름
- 매개변수
- 실행할 내용

강의에서는 메서드를 구성하는 기본적인 구문을 먼저 학습하였다.

---

## 10. 클래스의 구성 요소

강의에서는 클래스를 구성하는 주요 요소를 다음과 같이 정리하였다.

```text
Class
  │
  ├── 변수
  │
  └── 메서드
```

즉, 클래스 안에는 데이터를 저장하는 **변수**와 데이터를 다루는 **메서드**를 구성할 수 있다.

```text
클래스 = 변수 + 메서드
```

---

## 11. 메서드의 유형

메서드는 **반환 타입과 매개변수의 유무**에 따라 네 가지 유형으로 구분할 수 있다.

```text
반환값 O / 매개변수 O
반환값 O / 매개변수 X
반환값 X / 매개변수 O
반환값 X / 매개변수 X
```

이번 강의에서는 반환 타입과 매개변수의 존재 여부에 따라 메서드의 형태가 달라질 수 있다는 것을 학습하였다.

---

## 💡 새롭게 알게 된 점

이번 강의를 통해 Java의 변수는 단순히 값을 저장하는 것에서 끝나는 것이 아니라 **어떤 데이터를 저장하느냐에 따라 기본 타입과 참조 타입으로 구분된다**는 것을 학습하였다.

특히 기본 타입은 실제 값을 저장하고, 참조 타입은 주소값을 저장한다는 차이를 이해할 수 있었다.

또한 변수와 메서드가 서로 독립적인 개념이 아니라 클래스 내부를 구성하는 주요 요소라는 점을 알게 되었다.

```text
Class
= Variable + Method
```

변수가 데이터를 저장하는 역할이라면 메서드는 해당 데이터를 다루는 동작을 담당한다는 식으로 두 개념의 역할을 구분할 수 있었다.

마지막으로 메서드는 항상 같은 형태가 아니라 **반환 타입과 매개변수의 유무에 따라 네 가지 유형으로 나눌 수 있다**는 점도 새롭게 학습하였다.
