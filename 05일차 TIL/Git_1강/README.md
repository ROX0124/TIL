## 1. Git이란?

Git은 **분산형 버전 관리 시스템(Version Control System)**의 한 종류이다.

Git은 빠른 수행 속도에 중점을 둔 버전 관리 도구로, 프로젝트의 변경 내용을 시간에 따라 기록하고 관리할 수 있다.

---

## 2. 버전 관리

버전 관리는 파일의 변화를 시간에 따라 기록하고, 필요한 경우 특정 시점의 버전을 다시 가져올 수 있도록 관리하는 방식이다.

버전 관리를 사용하면 다음과 같은 작업이 가능하다.

- 각 파일을 이전 상태로 되돌리기
- 프로젝트 전체를 이전 상태로 되돌리기
- 시간에 따른 수정 내용 비교
- 누가 문제를 발생시켰는지 추적
- 누가 언제 이슈를 발생시켰는지 확인
- 파일을 잃어버리거나 잘못 수정했을 때 복구

즉, 프로젝트를 진행하면서 발생하는 다양한 변경 내용을 기록해두고 필요할 때 다시 확인하거나 복구할 수 있다.

---

## 3. Git이 필요한 이유

여러 사람이 함께 개발할 경우 개발 환경이나 코드 변경 사항을 서로 주고받는 과정에서 문제가 발생할 수 있다.

Git을 사용하면 같은 환경에서 작업할 수 있도록 도와 불필요한 시간을 줄일 수 있으며, 개발 과정에서 코드를 주고받을 때 발생할 수 있는 충돌을 최소화할 수 있다.

---

## 4. Git을 사용하는 방법

Git은 크게 CLI와 GUI 방식으로 사용할 수 있다.

### CLI

CLI는 **Command Line Interface**의 약자이다.

명령어를 입력하여 Git을 사용하는 방식이다.

### GUI

GUI는 **Graphics User Interface**의 약자이다.

화면을 통해 Git을 조작하는 방식이며, 강의에서는 예시로 **SourceTree**가 소개되었다.

---

## 5. Git 최초 설정

Git을 처음 사용할 때는 사용자의 이름과 이메일을 설정해야 한다.

### 사용자 이름 설정

```bash
git config --global user.name "(user_name)"
```

### 사용자 이메일 설정

```bash
git config --global user.email "(user_email)"
```

`--global` 옵션을 사용하여 Git에서 사용할 기본 사용자 정보를 설정한다.

---

## 6. Git 설정 확인

설정한 이름과 이메일은 다음 명령어로 확인할 수 있다.

### 사용자 이름 확인

```bash
git config --global user.name
```

### 사용자 이메일 확인

```bash
git config --global user.email
```

설정 이후에는 해당 명령어를 통해 입력한 정보가 정상적으로 등록되었는지 확인할 수 있다.

---

## 7. 기본 브랜치 이름 설정

Git에서 기본으로 사용할 브랜치 이름을 `main`으로 설정할 수 있다.

```bash
git config --global init.defaultBranch main
```

이를 통해 이후 Git 저장소를 생성할 때 기본 브랜치 이름을 `main`으로 사용할 수 있도록 설정한다.

---

## 💡 새롭게 알게 된 점

이번 강의를 통해 Git이 단순히 코드를 저장하는 도구가 아니라, **파일과 프로젝트의 변경 이력을 지속적으로 관리할 수 있는 버전 관리 시스템**이라는 점을 알게 되었다.

특히 문제가 발생했을 때 이전 상태로 되돌릴 수 있고, 여러 사람이 함께 개발하는 과정에서 누가 어떤 내용을 수정했는지 확인할 수 있다는 점이 중요하다고 느꼈다.

또한 Git을 사용할 때 명령어를 직접 입력하는 CLI 방식과 화면을 이용하는 GUI 방식이 존재한다는 점을 알게 되었다.

Git을 처음 사용하기 전에는 사용자 이름과 이메일을 설정하고, 기본 브랜치 이름도 설정할 수 있다는 점도 확인했다.
