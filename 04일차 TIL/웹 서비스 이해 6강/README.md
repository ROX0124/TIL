## 1. HTML의 기본 구조

HTML에서는 태그(Tag)를 이용하여 웹 페이지의 내용을 구성한다.

기본적인 형태는 다음과 같다.

```html
<tag attr="value">text</tag>
```

HTML 태그는 일반적으로 시작 태그와 종료 태그로 구성되며, 태그 내부에는 화면에 표시할 텍스트 등을 작성할 수 있다.

---

## 2. HTML Attribute

HTML 태그에는 **속성(Attribute)**을 추가할 수 있다.

기본적인 형태는 다음과 같다.

```html
<tag attr="value">text</tag>
```

여기서 `attr`은 속성의 이름이고, `value`는 해당 속성에 지정되는 값이다.

즉, 태그 자체만 사용하는 것이 아니라 필요한 정보를 속성으로 추가하여 태그를 구성할 수 있다.

---

## 3. 연산자

강의에서는 `=`와 `==`의 차이도 간단히 살펴보았다.

```text
=  : 할당 연산자
== : 동등 비교 연산자
```

두 기호가 비슷하게 생겼지만 역할이 서로 다르기 때문에 구분해서 사용해야 한다.

---

## 4. CSS의 기본 구조

CSS에서는 **선택자(Selector)**를 이용하여 스타일을 적용할 대상을 지정한다.

기본적인 형태는 다음과 같다.

```css
selector {
    key: value;
    key: value;
}
```

선택자를 통해 스타일을 적용할 대상을 정하고, 그 안에서 `key`와 `value`의 형태로 스타일을 지정한다.

---

## 5. CSS의 역할

CSS는 제작하고 있는 웹 페이지의 스타일을 꾸미는 역할을 한다.

HTML을 통해 페이지의 내용을 구성했다면 CSS를 이용하여 해당 페이지의 모습을 꾸밀 수 있다.

따라서 HTML과 CSS는 각각 다른 역할을 담당하면서 하나의 웹 페이지를 구성한다.

```text
HTML → 페이지 구성
CSS  → 페이지 스타일
```

---

## 6. HTML 주석

HTML을 작성할 때 코드에 주석을 사용할 수 있다.

VSCode에서는 다음 단축키를 이용하여 주석을 작성할 수 있다.

```text
Ctrl + /
```

주석을 활용하면 코드에 필요한 설명을 남기거나 특정 부분을 구분하는 데 사용할 수 있다.

---

## 7. 브라우저와 사용자 이벤트

사용자는 브라우저에서 다양한 행동을 수행할 수 있다.

예를 들어 사용자가 브라우저에서 값을 입력하는 것도 하나의 이벤트로 볼 수 있다.

즉, 웹 페이지에서는 사용자가 브라우저에서 수행하는 입력 등의 행동을 이벤트로 처리할 수 있다.

---

## 💡 새롭게 알게 된 점

이번 강의를 통해 HTML과 CSS를 작성할 때 각각 정해진 기본 문법이 있다는 것을 알게 되었다.

HTML은 태그와 속성을 이용해 내용을 구성하고, CSS는 선택자를 통해 대상을 지정한 뒤 `key: value` 형태로 페이지의 스타일을 설정한다는 차이를 이해할 수 있었다.

또한 `=`와 `==`는 비슷하게 보이지만 각각 할당과 비교라는 서로 다른 역할을 하기 때문에 구분해서 사용해야 한다는 점을 다시 확인했다.

마지막으로 사용자가 브라우저에서 입력하는 행동 역시 웹 페이지에서 처리할 수 있는 이벤트라는 것을 알게 되었다.
