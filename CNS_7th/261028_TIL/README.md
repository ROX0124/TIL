## 오늘 배운 것 — 나만의 언어로 설명
- HTML은 쉽게 말하면 웹 화면의 뼈대이다. 제목, 입력창, 버튼처럼 화면에 들어갈 요소를 구성한다.
- CSS는 쉽게 말하면 화면을 꾸미고 배치하는 규칙이다. 색상, 글꼴, 간격 등을 지정하고 화면 크기에 따라 배치를 바꿀 수 있다.
- JavaScript의 이벤트는 쉽게 말하면 사용자의 행동에 반응하는 기능이다. 버튼 클릭을 감지해 숫자를 증가시키거나 글자를 변경할 수 있다.
- React 컴포넌트는 쉽게 말하면 재사용할 수 있는 화면 부품이다. 수업 코드에서는 카운터 버튼과 소셜 링크 목록 등을 별도 파일로 분리했다.
- `useState`는 쉽게 말하면 컴포넌트가 기억하고 화면에 반영할 값을 관리하는 도구이다. 상태를 변경하는 함수를 호출하면 React가 변경된 값을 화면에 반영한다.
- `props`는 부모 컴포넌트가 자식 컴포넌트에 전달하는 데이터이다. `map`은 배열의 각 데이터를 화면 요소로 바꿀 때 사용할 수 있다.
- TypeScript의 `interface`는 데이터가 가져야 할 속성과 자료형을 정하는 약속이다.

프로젝트의 화면 연결 흐름은 `index.html → main.tsx → App.tsx → 하위 컴포넌트` 순서로 이해했다.

## 오늘 직접 작성한 코드
아직 독립적으로 재구현하기 전이며, 아래 카운터 예제를 직접 타이핑하면서 복습할 예정이다.

```tsx
import { useState } from 'react'

export default function CountPractice() {
  const [count, setCount] = useState(0)

  return (
    <button
      type="button"
      onClick={() => setCount(previous => previous + 1)}
    >
      클릭 횟수: {count}
    </button>
  )
}
```

이 예제에서 확인할 흐름은 `버튼 클릭 → setCount 호출 → 상태 변경 → 변경된 숫자 표시`이다.
